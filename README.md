## 📖 About

🔹 **Silhouette Connect Bridge** is a powerful tool built to help you design import and cut workflow bridge for Silhouette Connect. Silhouette Connect Bridge streamlines sending designs from Illustrator and CorelDRAW directly to your Silhouette cutter. Save material presets, manage cut settings per design type and maintain a job history.

## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Material Presets** | Save speed, force and pass settings per material type |
| **Design Queue** | Queue multiple designs for sequential cutting without manual setup |
| **Job History** | Track all cut jobs with material type and settings used |
| **Registration Marks** | Configure registration mark settings per design template |
